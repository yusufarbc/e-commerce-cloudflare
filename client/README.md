# 🛍️ E-Market: React Storefront (PWA)

This is the customer-facing storefront for the E-Market platform. Built using React, Vite, PWA capabilities, and Tailwind CSS, it is highly optimized for search engines (SEO), performance, and responsive screen sizes.

## 🚀 Features
- **Progressive Web App (PWA):** Off-line mode support and installable application shell.
- **Multilingual Support (i18n):** Configured for internationalization.
- **SEO Ready:** Dynamic Open Graph, structured JSON-LD data, and clean routing.
- **Smooth Interactions:** Glassmorphic modern design, micro-animations, shopping cart sidebars, and custom checkout flows.

## 📦 Scripts
- `npm run dev` - Launch development server.
- `npm run build` - Compile production package (`dist/`).
- `npm run preview` - Preview production build.
- `npm run lint` - Run ESLint verification.
